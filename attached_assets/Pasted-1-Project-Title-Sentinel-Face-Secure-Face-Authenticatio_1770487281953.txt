1. Project Title

Sentinel Face: Secure Face Authentication with Liveness Detection and Role-Based Access

2. Project Goal

Sentinel Face is a company login system where employees log in using face recognition instead of passwords, while ensuring the face is real and not spoofed.

The system:

Recognizes user face

Detects fake face attacks

Logs login activity

Redirects users to role dashboards

3. Problem Being Solved

Password-based systems have issues:

Password sharing

Weak passwords

Credential theft

Unauthorized access

Face login + liveness detection prevents these issues.

4. System Input and Output
Input

Live webcam frames of a user.

Example:
Employee looks at camera.

Output

System response:

User identified
Liveness verified
Access granted
Dashboard opened


or

Fake face detected
Access denied

7. Enrollment (Registration Flow)

First-time users register:

Capture 5–10 face frames
        ↓
Generate embeddings
        ↓
Average embeddings
        ↓
Store template


User role assigned during registration.

8. Verification (Login Flow)

During login:

Capture face
        ↓
Generate embedding
        ↓
Compare with stored templates
        ↓
Match user
        ↓
Check liveness
        ↓
Grant access

9. Liveness Detection (Anti-Spoof)

System prevents fake login using:

Blink Detection

Real humans blink; photos don't.

Motion Detection

Real faces move slightly.

Texture Detection

Skin texture differs from screens.

Combined score decides:

REAL or SPOOF

10. Role-Based Dashboard Navigation

Users have roles:

Role	Dashboard
Admin	Admin panel
Manager	Manager panel
Employee	Employee dashboard
Guest	Limited access

After login, system auto-navigates.

11. Audit Logging
