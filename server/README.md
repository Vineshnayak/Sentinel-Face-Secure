# Sentinel Face Secure Backend

This directory powers the backend API for Sentinel Face Secure. It runs a FastAPI web server using Docker and is configured for deployment to Hugging Face Spaces.

## Setup
The Hugging Face Space automatically builds the `Dockerfile` present in this directory and starts the server on port `7860`.
